BUG-SRV-01: Сброс фильтров при перезагрузке страницы

Описание: При обновлении страницы применённые пользователем фильтры сбрасываются к значениям по умолчанию.

Окружение: Google Chrome 141.0.7390.123, веб-версия

Шаги воспроизведения:

Перейти на https://www.sravni.ru/vklady/
Установить фильтры (например, ввести значение в поле «сумма вклада»)
Обновить страницу

Фактический результат: Фильтры возвращаются к значениям по умолчанию.

Ожидаемый результат: Установленные фильтры должны сохраняться после перезагрузки страницы.

Severity: Minor - не блокирует пользователя.  

Priority: Major - не блокирует пользователя (можно установить фильтры заново), но  портит опыт использования и увеличивает число повторных действий, особенно при сложной настройке нескольких фильтров одновременно.

BUG-SRV-02: Фильтр вкладов допускает логически несовместимые условия

Описание: Одновременный выбор условий «Капитализация» и «Регулярные выплаты» приводит к некорректным результатам выдачи.

Окружение: Google Chrome 141.0.7390.123, веб-версия

Шаги воспроизведения:

Перейти на https://www.sravni.ru/vklady/
Нажать «Все фильтры»
В разделе «Выплата процентов» выбрать «Капитализация (на тело вклада)» и «Регулярно»
Нажать «Показать»

Фактический результат: Система показывает 3 вклада.

Ожидаемый результат: Система не должна показывать вклады при логически несовместимых условиях фильтрации (либо должна явно предупреждать о несовместимости условий).

Severity: Major - пользователь получает недостоверную выдачу по факту начисления процентов.

Priority: Major - пользователь получает недостоверную выдачу (вклады, которые не соответствуют реальным условиям начисления процентов), что может привести к неверному финансовому решению, но не блокирует пользователя и не ломает основной сценарий подбора.

BUG-SRV-03: Зацикленная проверка оплаты блокирует интерфейс при выходе со страницы оплаты ОСАГО

Описание: При переходе на страницу оплаты ОСАГО и закрытии её без заполнения данных карты происходит перенаправление назад на страницу выбора типа оплаты, при этом запускается зацикленная проверка статуса оплаты, которая блокирует интерфейс - пользователь не может продолжить сценарий. Проблема устраняется перезагрузкой страницы (F5).

Окружение: Google Chrome 141.0.7390.123, веб-версия

Шаги воспроизведения:

Начать оформление ОСАГО, дойти до страницы оплаты
Закрыть страницу оплаты, не заполняя данные карты
Дождаться перенаправления на страницу выбора типа оплаты

Фактический результат: Происходит перенаправление на страницу выбора типа оплаты, запускается зацикленная проверка оплаты, интерфейс блокируется - пользователь не может продолжить оформление. Проблема исчезает после перезагрузки страницы (F5), после чего сценарий можно пройти заново.

Ожидаемый результат: При отмене оплаты пользователь должен корректно возвращаться к предыдущему шагу без зависания в состоянии проверки, без необходимости перезагружать страницу.

Severity: Critical - пользователь польностью не может продолжить сценарий без недокументированного workaround.

Priority: High - дефект полностью блокирует прохождение сценария оформления ОСАГО на одном из финальных шагов; workaround существует (перезагрузка страницы), но пользователь о нём не знает, что для части аудитории означает потерю сценария и уход к другому сервису.

BUG-SRV-04: Несоответствие предложенных кредитных продуктов выбранной цели кредита

Описание: При выборе цели кредита «Просто деньги» и типа продукта «Кредит» система выдаёт только предложения по кредиту на образование.

Окружение: Google Chrome 141.0.7390.123, веб-версия

Шаги воспроизведения:

Открыть раздел оформления кредита
Выбрать цель кредита «Просто деньги», тип продукта «Кредит»
Заполнить данные о заёмщике и месте работы
Перейти на страницу с кредитными продуктами

Фактический результат: Система показывает только кредиты на образование.

Ожидаемый результат: Система должна показывать кредитные продукты, соответствующие выбранной цели («Просто деньги»), а не продукты другой категории.

Severity: Major - для конкретной цели кредита выдача польностью нерелевантна. 

Priority: High - пользователь не может найти подходящий продукт по заявленной цели, что напрямую ломает ключевой сценарий сервиса (подбор кредита) и может привести к уходу пользователя к конкуренту.
