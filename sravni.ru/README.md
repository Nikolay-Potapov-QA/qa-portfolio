# Sravni.ru - исследовательское тестирование

## О проекте
Sravni.ru - сервис сравнения финансовых, страховых и образовательных
продуктов. Тестировалась веб-версия: сценарии оформления ОСАГО, кредита
и подбора вклада.

## Что сделано
- Провёл сессию исследовательского тестирования по 3 областям: ОСАГО,
  кредит, вклады и фильтры
- Обнаружил и задокументировал 4 дефекта с приоритетами High/Major
- Применённые техники: комбинаторное тестирование условий, тестирование
  прерывания сценария, проверка соответствия бизнес-логике

## Файлы
- `testing-notes.md` - документ по исследовательскому тестированию
- `bug-reports.md` - баг-репорты

## Инструменты
Google Chrome DevTools, ручное тестирование
